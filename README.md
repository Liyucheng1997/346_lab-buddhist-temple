# 汉传佛教寺院 · 程序化三维建模

一座按**伽蓝七堂**规制布局的明清官式佛寺，建筑与造像全部由代码生成（three.js），无外部模型/贴图资源。

在线浏览：<https://liyucheng1997.github.io/346_lab-buddhist-temple/>（推送 main 后由 GitHub Actions 自动烘焙造像、构建并部署到 GitHub Pages）

```bash
npm install
node tools/bake.mjs   # 预烘焙 30 尊造像网格到 public/statues/（约 15 秒，可选：不烘焙则首次加载时由 Web Worker 实时雕塑）
npm run dev           # http://127.0.0.1:5188
```

- `/`（index.html）：完整寺院场景，上方按钮巡礼各殿，悬停造像显示名号。
- `/statues.html`：造像工作台（单尊预览 / `?all=1` 画廊模式）。
- `/arch.html`：建筑工作台。

## 布局（自南向北的中轴）

影壁 → 山门 → 钟楼·鼓楼 → **天王殿**（弥勒佛居中、韦驮菩萨背立、四大天王分列东西）→ 香炉·石狮·幡杆 → **大雄宝殿**（横三世佛：药师佛·释迦牟尼佛·阿弥陀佛，迦叶、阿难侍立，十八罗汉分列两厢，海岛观音在后）→ 藏经楼。四周围墙。

## 技术

### 建筑 `src/temple/arch/`
参数化的明清官式构件：举折曲线与翼角起翘的屋面、筒瓦/瓦当/滴水、正吻与脊兽、斗拱（实例化）、隔扇门菱花格、须弥座台基与栏杆、匾额/对联（Canvas 文字）。

### 造像 `src/sculpt/`
一套自研的 **SDF 雕塑引擎**：
- `sdf.js`：有符号距离场基本体（球/椭球/圆锥胶囊/盒/环/柱）+ 平滑并/差/交 + 位移（衣纹、螺发、噪声、鳞甲）+ 半空间裁切 + 材质涂绘。
- `mesher.js`：窄带 Surface Nets 多边形化（分层包围剔除、逐块基本体筛选、梯度法线、SDF 环境光遮蔽、按材质分组）。
- `anatomy.js` / `bodies.js`：局部坐标系、头面部（怒相/笑相/老相）、手势（印相）、双段手臂 IK、飘带、衣纹投影。
- `buddhaHead.js` / `buddhaBody.js`：主尊坐佛的头与身。脸型、躯干、盘腿都是连续的解析场（正面轮廓 + 侧面轮廓放样，五官/衣纹为平滑位移），袈裟是覆在身上的等距“布层”，衣缘是干净的台阶与宽边。
- `faceCurves.js` / `faceDecal.js`：眉、眼线、朱唇、蝌蚪须用片元着色器按同一组特征曲线逐像素绘制，线条锐利，不受网格精度限制。
- `curls.js`：螺发为带螺旋纹的螺壳，InstancedMesh 实例化绘制。
- `statues/`：释迦牟尼/药师/阿弥陀（坐佛，不同手印）、弥勒、韦驮、四大天王（持国·琵琶，增长·剑，广目·蛇珠，多闻·伞鼠）、观音、迦叶/阿难、十八罗汉。
- 法器（剑、琵琶、伞、金刚杵、锡杖、钵、净瓶…）用精确几何体建模，保证锐利边缘。

造像网格预烘焙为 `public/statues/*.bin`（`node tools/bake.mjs [质量系数] [--force] [--only=id,id]`），运行时缺失则回退到 Web Worker 实时雕塑。
